# Claude skills by @sonicweights

Plain-text skill files for Claude. Each folder holds one `SKILL.md`.

| Skill | What it does |
|---|---|
| [`resume-tailor`](resume-tailor/SKILL.md) | Tailors a resume to one job post, honestly: skill match table, rewrites from your own facts, gaps and a learning plan. |
| [`interview-prep`](interview-prep/SKILL.md) | Practice interview on your own resume: finds the risky lines, asks one question at a time, gives feedback, ends with a scorecard. Practice only. |

## Cheatsheets
- [`ai-system-design-cheatsheet.png`](cheatsheets/ai-system-design-cheatsheet.png): how to answer "Design ChatGPT" in an interview (simplified).

## Use a skill
- **Claude app or website:** download the ZIP from [`zips/`](zips/), then Customize > Skills > + > Create skill > upload the ZIP.
- **Any AI chat:** open the skill's `SKILL.md`, copy all of it, paste it as your first message, then add your job post and resume.
